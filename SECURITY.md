# Security

Do not include credentials, session cookies, API keys, private platform source,
customer data, or internal infrastructure details in issues, pull requests,
examples, or test fixtures.

To report a suspected vulnerability privately, email **info@noirstack.com**
with the subject **Cascades Security Report** and include the affected package
or contract version, reproduction steps, expected and observed behavior, and
known impact.

Do not open a public issue for an unpatched vulnerability.

The private Cascades platform implementation is not part of this repository.
Reports involving the platform may use the same contact.
